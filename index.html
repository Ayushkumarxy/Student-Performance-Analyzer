02 · Tools

Importing libraries

import pandas as pd
import numpy as np
import matplotlib.pyplot as plt

Pandas handles the table of student data. pd is just a short nickname.

NumPy performs statistics such as mean, median and standard deviation.

Matplotlib draws the bar chart and histogram. plt is its nickname.

03 · Input

Reading the CSV file

data = pd.read_csv("students.csv")

This opens students.csv and stores the whole table inside a variable named data.

After this line, Python can access cells using row numbers and column names such as Name, Maths, Physics and Chemistry.

04 · Safety Check

Checking invalid marks

for i in data.index:
    name = data.loc[i, "Name"]
    maths = pd.to_numeric(data.loc[i, "Maths"], errors="coerce")
    physics = pd.to_numeric(data.loc[i, "Physics"], errors="coerce")
    chemistry = pd.to_numeric(data.loc[i, "Chemistry"], errors="coerce")

for i in data.index means: visit every student row one by one.

data.loc[i, "Name"] means: from the current row, take the value in the Name column.

pd.to_numeric(..., errors="coerce") tries to turn marks into numbers. If a value is something like abc, Pandas converts it to NaN (missing/invalid value) instead of crashing here.

if pd.isna(maths):
    print("Invalid marks for", name, "in Maths:", ...)
elif pd.isna(physics):
    ...
elif pd.isna(chemistry):
    ...

The if / elif chain asks: “Which subject has invalid marks?” and prints a useful message with the student's name and bad value.

Important: this block reports the first invalid subject found in a row. The actual removal happens later with dropna().

05 · Cleaning

Convert columns to numbers and remove bad rows

data["Maths"] = pd.to_numeric(data["Maths"], errors="coerce")
data["Physics"] = pd.to_numeric(data["Physics"], errors="coerce")
data["Chemistry"] = pd.to_numeric(data["Chemistry"], errors="coerce")

data = data.dropna()

Now the entire subject columns are converted into numeric form.

dropna() removes rows containing invalid/missing values. This prevents bad marks from corrupting totals and statistics.

06 · Calculation

Total and percentage

data["Total"] = (
    data["Maths"] +
    data["Physics"] +
    data["Chemistry"]
)

data["Percentage"] = data["Total"] / 3

Total = Maths + Physics + Chemistry. A new column called Total is created.

Because there are three subjects and each is treated as marks out of 100, dividing the total by 3 gives the percentage/average marks.

Example: 80 + 70 + 90 = 240 → 240 ÷ 3 = 80%.

07 · Decision Making

Assigning grades

grades = []
for percentage in data["Percentage"]:
    if percentage >= 90:
        grades.append("A")
    elif percentage >= 75:
        grades.append("B")
    elif percentage >= 60:
        grades.append("C")
    elif percentage >= 40:
        grades.append("D")
    else:
        grades.append("F")

data["Grade"] = grades

grades = [] creates an empty list.

The loop checks every student's percentage. The first matching condition decides the grade.

PercentageGrade
90+A
75–89.99B
60–74.99C

Below 40F

Finally the completed list becomes a new Grade column.

08 · User Choice

The menu

print("\nSTUDENT PERFORMANCE ANALYZER")
print("1. Result")
print("2. Statistics")
choice = int(input("Enter option: "))

The program pauses and asks the user to enter 1 or 2.

1 → show each student's result.
2 → analyze the whole class.

Because int(input(...)) expects a number, typing text such as “one” would raise an error. The current code does not handle that case.

09 · Option 1

Displaying student results

if choice == 1:
    print("\nStudent Results")
    for i in data.index:
        print(
            data.loc[i, "Name"], "|",
            int(data.loc[i, "Total"]), "|",
            format(data.loc[i, "Percentage"], ".2f") + "%", "|",
            data.loc[i, "Grade"]
        )

Again, the program visits each student row. It prints Name | Total | Percentage | Grade.

format(..., ".2f") keeps two digits after the decimal, so 65 becomes 65.00%.

Example output:
Aman | 240 | 80.00% | B

10 · Option 2

Class statistics

mean = np.mean(data["Percentage"])
median = np.median(data["Percentage"])
std = np.std(data["Percentage"])

Mean: ordinary class average.

Median: middle percentage after values are ordered.

Standard deviation: tells how spread out the percentages are. A smaller value means students are closer to each other; a larger value means performance varies more.

How does the topper logic work?
highest = data["Percentage"].max()
for i in data.index:
    if data.loc[i, "Percentage"] == highest:
        print("Topper:", data.loc[i, "Name"], ...)

The program first finds the highest percentage. Then it checks every student and prints anyone whose percentage equals that highest value. This also means tied toppers can all be printed.

How are subject averages calculated?
maths_average = data["Maths"].mean()
physics_average = data["Physics"].mean()
chemistry_average = data["Chemistry"].mean()

Each .mean() calculates the average marks of the entire class for that subject.

11 · Visualization

Turning numbers into charts

subjects = ["Maths", "Physics", "Chemistry"]
averages = [maths_average, physics_average, chemistry_average]
plt.figure()
plt.bar(subjects, averages)
plt.xlabel("Subjects")
plt.ylabel("Average Marks")
plt.title("Subject-wise Average")
plt.show()

The bar chart compares the average marks of Maths, Physics and Chemistry. Taller bar = higher class average.

plt.figure()
plt.hist(data["Percentage"])
plt.xlabel("Percentage")
plt.ylabel("Number of Students")
plt.title("Percentage Distribution")
plt.show()

The histogram groups students by percentage ranges. It helps you see where most students' percentages are concentrated.

13 · Mental Model

If you remember only 8 things, remember these

  1. Pandas opens and manages the student table.
  2. The program checks whether marks are valid numbers.
  3. Invalid rows are removed before calculations.
  4. Total = marks of all three subjects added together.
  5. Percentage = Total ÷ 3.
  6. if/elif/else converts percentage into a grade.
  7. Option 1 shows individual results; Option 2 analyzes the class.
  8. Matplotlib converts statistics into visual charts.
