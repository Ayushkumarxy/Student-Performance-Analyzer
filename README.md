# 🎓 Student Performance Analyzer

A beginner-friendly Python project for **BCA (AI & ML), Semester 1**. It analyses student marks from a CSV file and presents individual results, grades, class statistics and charts.

**Problem Statement:** 100  
**Course focus:** Programming Fundamentals and Logic Building Using Python  
**Author:** Ayush Kumar

## Project versions

- **Console application:** `one.py` — demonstrates Python functions, loops, conditions, CSV handling, Pandas, NumPy and Matplotlib.
- **Web application:** `app.py` — upload a CSV, inspect validation, view performance metrics and charts, and download analysed results.

## Features

- CSV upload and sample CSV download in the web application
- Required-column and marks validation
- Invalid rows are excluded and shown separately
- Total marks, percentage and grade for every valid student
- Class mean, median and population standard deviation
- Topper detection, including ties
- Subject-wise average chart and percentage distribution
- Downloadable analysed results
- Console menu with input re-prompting
- Automated tests for core calculations

## Grading rules

| Percentage | Grade |
|---:|:---:|
| 90–100 | A |
| 75–below 90 | B |
| 60–below 75 | C |
| 40–below 60 | D |
| Below 40 | F |

Each of the three subjects is marked out of 100. Percentage = total marks ÷ 3.

## Run locally

Use Python 3.10 or later.

```bash
python -m venv .venv
```

Activate the environment, then install dependencies:

**Windows PowerShell**
```powershell
.venv\Scripts\Activate.ps1
pip install -r requirements.txt
```

**macOS/Linux**
```bash
source .venv/bin/activate
pip install -r requirements.txt
```

Start the web application:

```bash
streamlit run app.py
```

Start the console application:

```bash
python one.py
```

Run automated tests:

```bash
python -m unittest discover -s tests -v
```

## CSV format

The CSV must contain these columns (spelling is case-sensitive):

```csv
Name,Maths,Physics,Chemistry
Aman,80,70,90
Riya,60,65,70
Karan,40,35,50
```

Marks must be numeric values from 0 through 100. Rows with a blank name or invalid marks are skipped. If no valid rows remain, the application explains the issue instead of attempting calculations.

## Statistics note

The standard deviation is the **population** standard deviation (`numpy.std` / `ddof=0`). This matches the original assignment calculation.

## Deployment

The included `render.yaml` configures a Streamlit web service on Render. Connect this GitHub repository to Render and deploy using the detected Blueprint. The deployed URL is generated by Render; it is not hard-coded here.
